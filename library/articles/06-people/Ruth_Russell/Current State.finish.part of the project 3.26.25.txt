🚀 How to Proceed to Next Steps
1. Merge the PR
The open PR (copilot/implement-upcoming-segments) contains all 40 segments. Review and merge it into your main branch.

2. Set your production environment variables
bash
# Required for webhook delivery (choose one or both)
export AIISTECH_WEBHOOK_BASE_URL=https://your-phasemirror-hq-host
export AIISTECH_WEBHOOK_TOKEN=your-remote-token

# Required to enable local bbolt subscriptions + DLQ
export AIISTECH_WEBHOOK_STORE_PROVIDER=true
export AIISTECH_WEBHOOK_SUBSCRIPTIONS_DB=/var/lib/aiistech/subscriptions.db

# IMPORTANT: Set this to protect admin endpoints
export AIISTECH_ADMIN_API_KEY=<strong-random-secret>

# Optional tuning
export AIISTECH_ADDR=:8080
export AIISTECH_LOG_LEVEL=INFO
export AIISTECH_SERVICE_NAME=aiistech-backend
export AIISTECH_REGISTRY_PATH=/etc/aiistech/sites.yaml
3. Containerize it
Create a Dockerfile (not yet in the repo):

Dockerfile
FROM golang:1.24-alpine AS build
WORKDIR /ap
COPY . .
RUN go build -o /aiistech-backend ./cmd/server

FROM alpine:3.19
COPY --from=build /aiistech-backend /usr/local/bin/
ENTRYPOINT ["/usr/local/bin/aiistech-backend"]
4. Deploy with a process supervisor or Kubernetes
The server handles SIGINT/SIGTERM for graceful shutdown and SIGHUP for site-registry hot-reload — it's ready for Kubernetes Deployment + ConfigMap out of the box.
