**DAY 1: ACCESS & EXPLORE (30 minutes)**

**Step 1: Activate Your Account**

1.  [ ] Check email for welcome message from Phase Mirror

2.  [ ] Click activation link

3.  [ ] Set your password (12+ characters, mix of
    letters/numbers/symbols)

4.  [ ] Configure MFA (scan QR code with authenticator app)

5.  [ ] Log in to your dashboard

**Step 2: Quick Platform Tour**

  ---------------- ----------------------------------------- ---------------------
  Area             What It Does                              Where to Find
  **Dashboard**    Overview of your AI governance status     Home screen
  **AI Systems**   Register and manage your AI systems       Left navigation
  **Dissonance**   View governance gaps and action items     Left navigation
  **Reports**      Generate compliance and board reports     Left navigation
  **Settings**     Manage users, integrations, preferences   Top right gear icon
  ---------------- ----------------------------------------- ---------------------

**Step 3: Invite Your Team**

1.  [ ] Go to **Settings → Users → Invite**

2.  [ ] Add email addresses for key team members

3.  [ ] Assign roles:

    -   **Admin** - Full access (IT lead)

    -   **Governance Lead** - Configure governance (compliance officer)

    -   **System Owner** - Manage specific AI systems (AI/ML leads)

    -   **Viewer** - Read-only dashboards (executives)

**Day 1 Checkpoint:** ☐ Logged in ☐ Team invited

**DAY 2: REGISTER YOUR FIRST AI SYSTEM (45 minutes)**

**Step 1: Prepare System Information**

Before registering, gather this information for one AI system:

  ---------------------- ------------------------------------------------------------------
  Field                  Your Information
  **System name**        \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_
  **Owner**              \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_
  **Business purpose**   \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_
  **Type**               ☐ ML Model ☐ LLM/GenAI ☐ Rules Engine ☐ Agent
  **Status**             ☐ Production ☐ Development ☐ Pilot
  **Data used**          ☐ Customer data ☐ Employee data ☐ Business data only
  **Regulations**        ☐ None ☐ GDPR ☐ HIPAA ☐ Fair Lending ☐ Other: \_\_\_\_\_
  ---------------------- ------------------------------------------------------------------

**Step 2: Register the System**

1.  [ ] Go to **AI Systems → Add System**

2.  [ ] Enter basic information (name, owner, description)

3.  [ ] Select system type and risk level

4.  [ ] Add regulatory tags (if applicable)

5.  [ ] Click **Save**

**Step 3: Upload Documentation (Optional but Recommended)**

Upload any existing documentation:

-   [ ] System design document

-   [ ] Model card or data sheet

-   [ ] Approval documentation

-   [ ] Monitoring specifications

**Day 2 Checkpoint:** ☐ First AI system registered

**DAY 3: RUN YOUR FIRST DISSONANCE ANALYSIS (30 minutes)**

**Step 1: Initiate Analysis**

1.  [ ] Go to **AI Systems → \[Your System\] → Analyze**

2.  [ ] Click **Run Dissonance Analysis**

3.  [ ] Wait 2-5 minutes for analysis to complete

**Step 2: Review Your Dissonance Report**

The report will show gaps between governance expectations and reality:

  ----------------------- -------------------------------------- --------------------------------------------------------------------
  Dissonance Type         What It Means                          Example
  **Documentation Gap**   Missing or outdated documentation      \"No validation report found\"
  **Policy Mismatch**     Policy says X, implementation does Y   \"Policy requires quarterly review, last review was 8 months ago\"
  **Oversight Gap**       Insufficient human oversight           \"No approval workflow for model changes\"
  **Monitoring Gap**      Missing or insufficient monitoring     \"No bias monitoring configured\"
  ----------------------- -------------------------------------- --------------------------------------------------------------------

**Step 3: Create Action Items**

For each dissonance:

1.  [ ] Click **Create Lever**

2.  [ ] Assign an owner

3.  [ ] Set a target date

4.  [ ] Add notes on remediation approach

**Day 3 Checkpoint:** ☐ First dissonance report reviewed ☐ Action items
created

**Step 2: Batch Register**

**Bulk Import** feature under **AI Systems → Import** if you have many

**Step 3: Run Dissonance Analysis on All**

1.  [ ] Go to **Dissonance → Analyze All**

2.  [ ] Review findings across your portfolio

3.  [ ] Prioritize critical gaps

**Day 4 Checkpoint:** ☐ 5 AI systems registered ☐ Portfolio-wide
analysis complete
