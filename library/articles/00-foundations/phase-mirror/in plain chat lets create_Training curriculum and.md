**CURRICULUM OVERVIEW**

**Training Philosophy**

Phase Mirror training follows the **\"Learn, Practice, Apply\"** model:

  -------------- ---------------------------------------- -----------------------------------
  Stage          Description                              Activities
  **Learn**      Understand concepts and features         Videos, reading, demonstrations
  **Practice**   Hands-on exercises in safe environment   Sandbox exercises, simulations
  **Apply**      Use skills on real work                  Guided real-world tasks, coaching
  -------------- ---------------------------------------- -----------------------------------

**COURSE CATALOG**

**PM-100: PLATFORM FUNDAMENTALS**

**All Users \| 30 minutes \| Required**

**Course Description**

Introduction to Phase Mirror for all users. Covers platform navigation,
core concepts, and basic operations regardless of role.

**Learning Objectives**

By the end of this course, learners will be able to:

-   Explain the purpose and value of Phase Mirror

-   Navigate the platform interface confidently

-   Understand core terminology (dissonance, levers, governance)

-   Access help and support resources

-   Complete basic platform operations

**Course Outline**

  --------------------------------- ---------- ------------------------------------------------------------------
  Module                            Duration   Topics
  **1.1 Welcome to Phase Mirror**   5 min      What is Phase Mirror, why it matters, the governance gap problem
  **1.2 Core Concepts**             10 min     Mirror-Dissonance-Phase methodology, key terminology
  **1.3 Platform Navigation**       10 min     Dashboard, menus, search, keyboard shortcuts
  **1.4 Getting Help**              5 min      Help center, support channels, community
  --------------------------------- ---------- ------------------------------------------------------------------
