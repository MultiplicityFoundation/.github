Operator‑First Arithmetic (ii) as an Initiality
Principle
Aim
Package numerals-as-iterators as an initiality statement (“⟨s⟩ is the free monoid on one generator realized
inside End(N )”), and show how the usual Natural Numbers Object (NNO) story is recovered by adding a
basepoint z and the recursion/universal property.




1. Pointed monoids and the free monoid on one generator

1.1 Pointed monoids

A pointed monoid is a pair (M , m) where M is a monoid and m ∈ M is a distinguished element.


Let Mon∗ be the category: - Objects: pointed monoids (M , m). - Morphisms: monoid homomorphisms
h : M → M ′ such that h(m) = m′ .

1.2 Initiality (free on one generator)

The free monoid on one generator is the initial object in Mon∗ .


A standard choice is (N0 , +, 0; 1): - underlying monoid (N0 , +, 0) - distinguished element 1


Universal property (initiality): For every pointed monoid (M , m), there exists a unique pointed-monoid
morphism


                                     ϕm : (N0 , +, 0; 1) → (M , ⋅, e; m)

with ϕm (1) = m. Necessarily,
               \phi_m(n)=m^n\quad\text{(the KATEX16-fold product of KATEX17 in KATEX18).}


       Intuition: the “number” n is the operator “apply the generator n times.”




2. Realizing the free monoid inside End(N )

2.1 The endomorphism monoid

Fix an object N in a category C . Its endomorphisms




                                                      1
                                             End(N ) := C(N , N )

form a monoid under composition (∘) with unit idN .


Pick a distinguished endomorphism


                                                  s : N → N.

Then (End(N ), s) is a pointed monoid.


2.2 The iterator homomorphism

By initiality of (N0 , +, 0; 1) in Mon∗ , there is a unique pointed-monoid morphism


                                   Φs : (N0 , +, 0; 1) → (End(N ), ∘, idN ; s)

with Φs (1) = s. Concretely:

                               Φs (n) = sn := s ∘ s ∘ ⋯ ∘ s,       Φs (0) = idN .
                                                   n times


2.3 The realized free submonoid ⟨s⟩

Define the submonoid generated by s:


                                      ⟨s⟩ := {sn ∣ n ∈ N0 } ⊆ End(N ).

Then: - im(Φs ) = ⟨s⟩ - ⟨s⟩ is a realization of the free monoid on one generator inside End(N ) exactly to
the extent that Φs is injective.


2.4 “No‑collapse” / faithfulness axiom (to match standard N)

To ensure distinct numerals correspond to distinct iterators, impose:


                                            sm = sn ⟹ m = n.

Equivalently, Φs is an embedding of monoids, so ⟨s⟩ ≅ (N0 , +, 0).




3. OFA(ii): numerals are iterators; values are induced

3.1 Definition (numerals as iterators)

In OFA(ii), a numeral is literally an endomorphism:


                                              n := sn : N → N .




                                                        2
Arithmetic at the operator level is induced by the monoid laws: - Addition: m + n = m ∘ n. -
Multiplication: mn = (m)∘n = smn .


3.2 Induced “value at zero” map (recovering (i))

Add a basepoint (global element)


                                                  z : 1 → N.

Then each iterator yields a “value”:

                                        n := n ∘ z = sn ∘ z : 1 → N .

So (i) is an evaluation of (ii).




4. Recovering the NNO story by adding z + recursion

4.1 NNO universal property (recursion)

A Natural Numbers Object in C (with terminal object 1) is a triple (N , z, s) such that for every object A,
every point q : 1 → A, and every endomorphism f : A → A, there exists a unique morphism u : N → A
satisfying:


                                        u ∘ z = q,          u ∘ s = f ∘ u.

This is the categorical form of primitive recursion/iteration.


4.2 NNO as an initial algebra for F (X) = 1 + X

When C has coproducts, the same structure can be packaged as an initial algebra for the endofunctor


                                               F (X) = 1 + X.

The structure map α : 1 + N → N is determined by z and s, and initiality of (N , α) is equivalent to the
recursion property above.


        This is the cleanest “no extra normalization needed” route: uniqueness comes from initiality.


4.3 How recursion links back to iterators (OFA(ii) → semantics)

Given recursion data (A, q, f ), the unique u : N → A satisfies, for all n:


                                                u ∘ sn = f n ∘ u

and in particular on the induced numerals:

                                   u(n) = u ∘ sn ∘ z = f n ∘ u ∘ z = f n (q).



                                                        3
So numerals-as-iterators become the universal indexing of iterates of any process f starting from any
seed q .


4.4 Recovering addition and multiplication (usual arithmetic)

From the NNO recursion principle one defines (uniquely) the standard maps


                                     + : N × N → N,          ×:N ×N →N

by primitive recursion. For example, addition is characterized by:

                                       a + 0 = a,       a + s(b) = s(a + b).

Then one proves (internally) the compatibility with iterators:

                                                   sm (n) = n + m,

i.e. each iterator sm is “add m” once addition is defined.


Key takeaway: - OFA(ii) gives you the operator monoid ⟨s⟩ immediately. - Adding z and requiring the
recursion universal property upgrades (N , z, s) to an NNO, from which full arithmetic is recoverable.




5. The conceptual package (one line)
           OFA(ii) = the claim that the natural numbers are the free monoid on one generator, realized
           as the submonoid ⟨s⟩ ⊆ End(N ), and that numerical “values” are obtained by evaluation at
           a basepoint z ; imposing the NNO recursion property makes (N , z, s) the canonical object
           supporting iteration/recursion in C .




6. Fast falsifiability / validation checklist
     1. Monoid-theoretic check: Verify that Φs is a monoid homomorphism with image ⟨s⟩.
     2. No-collapse check: Determine whether sm = sn ⇒ m = n holds in the intended model.
     3. NNO check: With a chosen z , test the recursion property by constructing the unique u for arbitrary
           (A, q, f ) and checking uniqueness.
     4. Cross-model invariance: Compare a syntactic rewrite model and a semantic model (e.g. Sets/Types)
        and show they agree on closed terms via the initiality map.
