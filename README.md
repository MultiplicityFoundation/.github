# Multiplicity Ecosystem

*A unified substrate for verifiable intelligence, social physics, and civic infrastructure.*

---

## Overview

This repository serves as the central landing page and organizational profile for the Multiplicity ecosystem. Our work spans from formal mathematical proofs and high-performance compiler engineering to decentralized social systems and civic infrastructure.

We operate across three primary domains:

1.  **[PhaseMirror-HQ](https://github.com/Multiplicity/PhaseMirror-HQ)**: The Research & Engineering Hub. Focuses on **PIRTM** (Prime-Indexed Recurrence Tensor Machine) and the **MLIR → LLVM** optimization pipeline for verifiable compute.
2.  **[agiOS](https://github.com/Multiplicity/agiOS)**: The Proof-Carrying Substrate. A verifiable operating system implementing **StabilityGate** and **CCRE** for governed runtime enforcement.
3.  **[multiplic](https://github.com/Multiplicity/multiplic)**: The Application & Site Registry. A collection of sovereign tools and platforms, including **Citizen Gardens**, **EchoBraid**, and **Multiplic Studio**.
