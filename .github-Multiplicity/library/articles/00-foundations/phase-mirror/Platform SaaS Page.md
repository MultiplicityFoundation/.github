Phase Mirror Oracle {#phase-mirror-oracle .hero-title}
===================

A callable, auditable inconsistency-finding protocol that outputs
deterministic dissonance reports. Deploy as control surface in PR
checks, merge queues, drift detection, and incident response.

::: {.platform-intro}
The Phase Mirror Oracle is the technical core---an open-core platform
with managed service restriction. Self-hosting permitted. Modification
permitted. Managed service requires commercial agreement.
:::
