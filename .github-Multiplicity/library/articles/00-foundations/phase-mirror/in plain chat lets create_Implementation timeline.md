**COMMUNITY CHECKLIST**

**Setup (30 minutes)**

-   \[ \] Go to
    [[phasemirror.com/signup]{.underline}](http://phasemirror.com/signup)

-   \[ \] Create account with email

-   \[ \] Verify email address

-   \[ \] Set password and configure MFA

-   \[ \] Accept Terms of Service

-   \[ \] Complete brief onboarding survey

**Configuration (30 minutes)**

-   \[ \] Take 5-minute platform tour

-   \[ \] Invite up to 2 additional users (3 total for Community)

-   \[ \] Review default settings

**First AI System (45 minutes)**

-   \[ \] Click **AI Systems → Add System**

-   \[ \] Enter basic information:

    -   System name

    -   Description

    -   Type (ML Model, LLM, etc.)

    -   Risk tier (self-assessed)

-   \[ \] Upload any existing documentation

-   \[ \] Save system

**First Analysis (30 minutes)**

-   \[ \] Go to registered system

-   \[ \] Click **Analyze**

-   \[ \] Wait for analysis (2-5 minutes)

-   \[ \] Review Dissonance Report

-   \[ \] Note any action items

**Ongoing (self-managed)**

-   \[ \] Add more systems as needed

-   \[ \] Run periodic analyses

-   \[ \] Access community forums for questions
