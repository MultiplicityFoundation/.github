Our Diagnostic Process {#our-diagnostic-process .section-title}
----------------------

The Phase Mirror Dissonance methodology follows a repeatable five-step
loop designed to extract signal from complexity.

::: {.process-steps}
::: {.process-step}
::: {.step-number}
1
:::

### Extract {#extract .step-title}

Identify stated goals, implicit fears, constraints, stakeholders, and
timelines from organizational context.
:::

::: {.process-step}
::: {.step-number}
2
:::

### Map Tensions {#map-tensions .step-title}

Surface contradictions between stated goals and operating incentives,
rhetoric and infrastructure.
:::

::: {.process-step}
::: {.step-number}
3
:::

### Rank Tensions {#rank-tensions .step-title}

Prioritize using impact × tractability formula to focus effort where it
matters most.
:::

::: {.process-step}
::: {.step-number}
4
:::

### Produce Levers {#produce-levers .step-title}

Generate concrete interventions with clear owners, measurable metrics,
and defined time horizons.
:::

::: {.process-step}
::: {.step-number}
5
:::

### Bind Governance {#bind-governance .step-title}

Replace abstract intentions with auditable artifacts: specs, contracts,
SLAs, kill-switches.
:::
