Phased plan (directory-based site isolation)

Exit criteria

ADR steps (aligned to #1)
ADR Step A — Site isolation is directory-based under state/<site_id>/
Decision All governed state and orchestration artifacts are stored under a site-root directory:

state/<site_id>/...
Rationale

Simple, auditable, local-first, easy to diff and snapshot.
Makes site separation explicit and inspectable on disk.
Acceptance criteria

No governed artifacts are written outside state/<site_id>/ for any tool invoked with that site_id.
A default site (local) maps to state/local/.
ADR Step B — Canonical Site Registry defines admissible site_ids
Decision A single contract-owned registry defines:

allowed sites
optional metadata (env, region, owner)
default site
Rationale

   Introduce new sites in one place” becomes a contract change, not a runtime tweak.
Acceptance criteria

Adding a new site requires modifying exactly one registry file.
Invalid site_id fails with a clear error (not silent fallback).
ADR Step C — Introduce site_paths as the only way to resolve storage locations
Decision All runtime modules must call a shared path resolver (no ad hoc string paths).

Rationale

Guarantees consistent directory layout.
Enables future migrations (e.g., moving some stores to S3) without rewriting every tool.
Acceptance criteria

Lint/test (or code review gate) ensures no direct writes to state/ paths outside site_paths.
ADR Step D — MCP tools must be site-aware for stateful operations
Decision Stateful MCP tools accept site_id (optional, default local) and operate exclusively within that site root.

Acceptance criteria

Tool registry declares site_id? for all stateful tools.
Tool output includes site_id in metadata/audit.
ADR Step E — Site bootstrap & health are mandatory before enabling a site
Decision A site is “admissible” only after passing:

site_bootstrap(site_id)
site_health(site_id)
Acceptance criteria

site_health fails if required directories/ledgers are missing.
site_bootstrap does not mutate other sites.
